KiraUtils

A toggleable utility collection. Open plugin settings after installing to control each feature without having to uninstall and reinstall the plugin.

Install

  1. Open your compatible Discord client's Plugins page.
  2. Paste this folder URL into the installer.
  3. Enable the features you want in KiraUtils settings.
