Local Edit
Remastered

Change how any message appears on your device, including your own. Your local edits are saved by the plugin and are not sent to Discord or shown to other people.

Install · Test build 3

  1. Open Discord in a compatible Revenge, Kettu, or Vendetta-based client.
  2. Go to the client's Plugins page.
  3. Copy the raw GitHub folder URL below and paste it into Kettu's plugin installer. Kettu will fetch manifest.json from this location.
  4. Long-press any message and choose Edit Locally. The plugin setting controls whether the action also appears on your own messages.
